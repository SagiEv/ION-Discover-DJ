# Library & Browsing

DiscoverTube DJ v2.0.0 introduces a powerful, modal-based track browsing experience designed for seamless file management and track discovery.

## The Browse Modal
The `BrowseModal` is a central hub for accessing both your downloaded tracks and your local filesystem. It overlays the main UI, allowing you to quickly find and load tracks without disrupting the flow of your mix.

### Key Features
- **Filesystem Navigation:** Browse your local directories directly within the app.
- **Tag Extraction & Searching:** Automatically extracts metadata (like artist and title) from your audio files. You can instantly search through your collection using these tags.
- **Direct Deck Loading:** Click a track in the browser to instantly load it into Deck A or Deck B.
- **YouTube Integration:** The Browse Modal seamlessly integrates with the YouTube download flow. If you search for a track that isn't in your local library, you can trigger a YouTube search and download it on the fly.

## Directory Management
By default, all downloaded songs and processed stems are saved to specific directories. You can customize these locations via the new **Settings Configuration Modal**.
