# Settings Configuration Modal

DiscoverTube DJ v2.0.0 introduces a dedicated Settings Configuration Modal, allowing you to easily customize application behavior and storage paths.

## Storage Configuration
You can customize the directories where the application saves media:
- **Root Songs Directory:** The primary folder where all downloaded YouTube tracks and fetched subtitles are stored.
- **Stems Storage Directory:** A separate folder designated for storing the isolated AI stems (Vocals, Drums, Bass, Other).

## Processing Settings
- **Auto-process AI Stems:** You can toggle a setting to automatically queue newly downloaded songs for AI stem separation in the background. If disabled, you can manually queue tracks by dragging a song to the AI Stems Manager.

All settings are persisted and reloaded automatically when you start the application.
